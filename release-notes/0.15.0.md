# Seneca 0.15.0

- Home brings Today, Classes, Chat and Calendar into one window.
- The companion shows a small study suggestion indicator and answers in an anchored bubble.
- Save typed lines, clipboard items, photos and screen regions into classes. Practice misses and marked replies come back in review.
- Set up classes and nudge preferences in Home. See a streak and locally calculated study recaps.
- Installed Windows copies can update in Seneca. On Mac, Settings → Updates verifies the ZIP for your processor before you replace the app.

## Known issues

- The tutor displays complete provider responses in the bubble. Keys and cloud request review use the existing connection.
- Windows binaries are unsigned. Mac builds are ad hoc signed and need manual replacement. They are not notarized.
- Physical hotkeys, macOS screen recording permissions and provider hardware still need target-device acceptance.
- The Windows portable ZIP is above the 150 MB target. Full assistive-technology acceptance and removal of legacy support windows are pending.
