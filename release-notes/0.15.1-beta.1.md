## Seneca 0.15.1-beta.1

This is a test build. The stable download remains 0.14.1 while Windows 11 hands-on testing is pending.

- Setup fills Home and shows all five steps. Enter continues from the name field or adds classes on the next step.
- Set a weekly class schedule from setup or Calendar with one form, multiple weekdays, hour-and-minute times and an editable term end.
- Captured today shows text and image previews. The editor closes after saving, with a small receipt for Undo, Move and Open note.
- Seneca's chat bubble points at the companion. Morning nudges stay in the morning, and class quiet is on by default.
- Calendar moves meeting controls onto the timetable. The topic input stays in place and clears after Add, and topic actions require a selection.
- Study rooms, the document workspace, the weekly summary, quick actions, appearance and local tools now open inside Home.

Windows has an installer and two portable archives. The smaller 7z archive opens with Windows 11 24H2 or 7-Zip. Use the ZIP for wider extractor compatibility. For Mac, choose arm64 for Apple Silicon or x86_64 for Intel.

Study data and saved connections live in the existing protected profile. Usage counts stay local in this beta. The Windows installer is unsigned, and Mac builds are ad hoc signed without notarization.
